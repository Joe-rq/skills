# PPT 方法论：检查清单与约束

本文件供 `ppt-methodology-coach` skill 在 Phase 4~6 按需读取。不要一次性加载所有内容，只读当前阶段需要的部分。

## 内容审检查清单

逐页回答以下问题：

- [ ] 这一页的核心信息能否用一句话说出来？
- [ ] 标题是否准确概括了本页内容？
- [ ] 数据、引用、事实是否有来源或标注？
- [ ] 逻辑是否自洽？前提 → 论据 → 结论是否成立？
- [ ] 有没有与目的无关的信息可以删除？
- [ ] 本页与上下页的衔接是否自然？
- [ ] 对于说服型 PPT：本页是否指向最终判断？
- [ ] 对于理解型 PPT：本页是否降低了认知负担？

## 视觉审检查清单

- [ ] 整套 PPT 是否严格使用 Phase 3 锁定的风格？
- [ ] 配色是否在投影/屏幕上清晰可辨？
- [ ] 字体层级是否一致？（标题、正文、注释的字号、字重）
- [ ] 对齐是否统一？（左对齐/居中对齐不要混用）
- [ ] 留白是否足够？页面不拥挤
- [ ] 重点信息是否通过大小、颜色、位置被强调？
- [ ] 图片/图表风格是否统一？

## 体验审检查清单

- [ ] 观众第一眼会看哪里？是否是本页最重要的信息？
- [ ] 信息出现的节奏是否符合演讲逻辑？
- [ ] 每页内容量是否适合给定演讲时长？
- [ ] 复杂概念是否被拆成了多页，而不是一页塞满？
- [ ] 结尾是否有明确的行动呼吁或核心结论？

## 素材约束清单

为每页判断是否需要素材。如果需要，必须满足：

- [ ] logo 保持官方原貌，不改颜色、不变形
- [ ] 截图/图片尺寸一致，风格统一
- [ ] 图片分辨率足够，在投影/大屏上不模糊
- [ ] 素材有明确来源或生成方式说明
- [ ] 每页素材数量 ≤ 2，避免堆砌
- [ ] 素材必须服务于信息表达，而不是装饰

## 图表/动效过滤问题

每增加一个图表、3D/插画或动效前，必须回答：

1. 这个元素呈现什么信息？
2. 如果不加它，信息会不会变难懂？
3. 它是否比纯文字更高效？
4. 风格是否与 Phase 3 锁定的视觉一致？

只有第 2 题回答「会」或第 3 题回答「是」时，才建议加入。

## 输出格式选择表

| 场景 | 推荐格式 | 原因 |
|------|---------|------|
| 在线演示、可交互 | 网页/HTML | 便于链接分享、嵌入多媒体 |
| 正式汇报、可编辑 | PPTX | 通用格式，便于后续修改 |
| 存档、打印、分发 | PDF | 版式固定，跨设备一致 |
| 快速预览、手机查看 | PDF 或网页 | 兼容性最好 |

## 人工微调必查项

最终输出前，人必须检查：

- [ ] 文字没有被截断或溢出文本框
- [ ] 标题层级在全局保持一致
- [ ] 配色在目标显示设备上可见
- [ ] 动画/切换效果不花哨、不拖沓
- [ ] 页码、logo、日期等重复元素位置一致
- [ ] 文件大小适合传输场景
